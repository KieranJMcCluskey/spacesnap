# Dementia Support Snap: Is a variation of the Jess Learns to Code Space Snap


Using the same framework as the Jess Learns to Code game but with a slower card flip time
and standard recognisable household items. This game is tailored to provide a fun stimulating 
experience for those suffereing from Dementia & Alzheimer's
