# Space Snap: A Web Game Adventure
### Chapter files for *Jess's Coding Adventure 3*

Each file is the complete working game at the end of the chapter listed.
Open the file for the chapter you are on if you need to check your code.

Open any .html file by double-clicking it. It will open in your web browser.

You need an internet connection to load the NASA space background image.

---

## Chapter Files

| File | Chapter | What is added |
|------|---------|---------------|
| `spacesnap1.html` | Chapter 1 | Basic HTML structure, Hello Space! |
| `spacesnap2.html` | Chapter 2 | CSS grid layout, 16 cards |
| `spacesnap3.html` | Chapter 3 | NASA space background, gold styling |
| `spacesnap4.html` | Chapter 4 | Card front and back faces with emojis |
| `spacesnap5.html` | Chapter 5 | 3D flip CSS structure (not yet interactive) |
| `spacesnap6.html` | Chapter 6 | First JavaScript, cards flip when clicked |
| `spacesnap7.html` | Chapter 7 | Match checking, green glow for matched pairs |
| `spacesnap8.html` | Chapter 8 | Win screen and Play Again button |
| `spacesnap9.html` | Chapter 9 | Move counter and card shuffle |
| `spacesnap_final.html` | Chapter 10 | The complete finished game |

---

## How to Open Your File

- **Windows**: Find the file in File Explorer and double-click it
- **Mac**: Find the file in Finder and double-click it

To see changes after editing: press **F5** (Windows) or **Command+R** (Mac) in your browser.

---

## NASA Background Image

The space background loads from NASA's image library at:
https://images.nasa.gov

You can find your own favourite space image there and replace the URL in the CSS.
Everything on NASA's image library is free to use.
